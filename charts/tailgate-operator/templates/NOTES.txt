### Create an EgressGroup

Give a set of pods native tailnet egress through one shared gateway:

  cat <<EOF | kubectl apply -f -
  apiVersion: tailscale.rajsingh.info/v1alpha1
  kind: EgressGroup
  metadata:
    name: my-egress
  spec:
    mode: cgnat
    attach: routed
    replicas: 1
    selector:
      podSelector:
        matchLabels:
          tailgate.rajsingh.info/egress: my-egress
  EOF

### Check Status

  kubectl get egressgroups
  kubectl describe eg my-egress

View operator logs:

  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=operator -f
